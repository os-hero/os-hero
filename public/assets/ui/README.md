# Guild UI Assets

- `guild-frame.png` is a transparent raster frame generated with ImageGen for the selected Guild Equipment concept on 2026-10-13. Use only as a restrained CSS border-image ornament; its center must remain transparent.
- It does not replace, crop or recolor character, equipment or background sprites. The shared native renderer remains their source.
- Unmodified Google Fonts Press Start 2P is bundled for offline branding in `../fonts/press-start-2p/` with its OFL license and FONTLOG. Body text keeps the system font.
- Other games' research screenshots are reference material only, not application assets.

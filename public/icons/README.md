# UI icons

Lucide SVG icons vendored from the official `lucide-icons/lucide` repository,
tag `0.468.0`, directory `icons/`. Licensed under the included ISC license.
No icon runtime package or remote request is required by the app.

`chevron-right.svg` uses the official repository's matching path, retrieved 2026-10-06.
`circle-slash.svg` and `rotate-ccw.svg` use the same pinned official source for empty equipment and outfit reset.
